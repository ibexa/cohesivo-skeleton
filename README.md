# Cohesivo skeleton

This is a Symfony Flex project skeleton for Cohesivo. It requires a subscription.

Learn more about [Cohesivo](https://cohesivo.com/).

## Installation

Create a new project using Composer:
```
composer create-project ibexa/cohesivo-skeleton cohesivo_website
```
